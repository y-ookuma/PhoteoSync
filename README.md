# 🌱☀️ PhoteoSync

**「今日、うちの畑・ハウスに光は足りてる？」がひと目でわかる！**

現在地の気象データをサクッと取得して、気温・日射量・雨量はもちろん、植物育成に超重要な **PAR（光合成有効放射）・PPFD（光量子束密度）・DLI（1日の積算光量子量）** までグラフと表でまるっと可視化してくれる、インストール不要・単一HTMLファイルの軽量ツールです✨

サーバー不要、アプリ不要、ブラウザで開くだけ。位置情報を許可するだけで、今すぐ自分の畑の"光事情"がわかります🌾

タイトルの「PhoteoSync」自体が本READMEへのリンクになっているので、アプリを開いた人はいつでもここに戻ってこられます🔗

---

## 🚀 できること

* 📍 **現在地オート検出**：ブラウザの位置情報から緯度・経度を取得し、国土地理院APIで「〇〇市〇〇」までパッと表示
* 🗓️ **日付切り替えボタン**：`-15日 / -7日 / -3日 / 本日 / +3日 / +7日 / +15日` をワンタップで行き来
* 📊 **重ねグラフ表示**：気温・短波放射・PAR・PPFD・雨量などを1枚のグラフに集約（Chart.js製）
* 🌗 **昼夜背景表示**：日の出〜日の入りを白、夜間をグレーで表示して、光のある時間帯を直感的に確認
* 🌅 **日の出・日の入りを自動計算**：現在地と日付から日の出・日の入りを計算
* 🌙 **極夜・白夜にも対応**：太陽が昇らない極夜、太陽が沈まない白夜も判定
* 🇯🇵 **時刻はJST（Asia/Tokyo）で統一**：ブラウザ側のタイムゾーンに依存しない時刻処理
* 🧮 **自動集計テーブル**

  * 本日：1時間ごとの明細＋その日のサマリー
  * 期間表示：日ごとの集計、日付タップでその日の詳細にジャンプ
* ⬇️ **CSVダウンロードは用途に合わせて4種類**

  * 「⬇ CSV」（グラフ右上）：表示中データを1時間刻みでそのまま出力
  * 「⬇ 日計CSV」：日別集計テーブルと同じロジックで、日ごとの最高/平均/最低気温・短波放射・散乱光比率・PAR・DLI・雨量・日出・日入をまとめて出力
  * 「⬇ CSV」（過去5年分・各グラフ右上）：その項目1つ分の生値＋移動平均データを年ごとに出力
  * 「⬇ CSV」（積算データ）：起算日から本日+90日までの積算気温・積算短波放射・積算雨量を、実測/予報か過去5年平均補完かの内訳つきで出力
* 🖼️ **グラフはPNG画像としても保存可能**：通常表示のメイングラフ、過去5年分の各グラフ、積算データグラフ、それぞれに「⬇ グラフPNG」ボタンを設置
* 📈 **過去5年分の気象比較**：最低/平均/最高気温・降水量・短波放射量を年ごとに重ねて表示し、7日／14日／30日の移動平均で傾向を比較（ズーム・パンは5グラフ連動）
* 📊 **積算データ（新機能）**：カレンダーで起算日を指定すると、そこから本日+90日先まで平均気温・短波放射・雨量を積算してグラフ化。実測・予報データが無い先の期間は過去5年の同日平均値で自動補完
* 📖 **用語解説（開閉式）**：短波放射・PAR・PPFD・DLIの意味に加え、🍅トマト・🥒キュウリ・🍓いちごの**目標DLI早見表**と出典リンクつき
* 📱 **スマートフォン対応**：グラフ・表は狭い画面でも横スクロール可能
* ⚡ **バックエンド不要**：HTML / CSS / JavaScriptだけで動作

## 🕹️ 使い方はかんたん3ステップ

1. `index.html`（PhoteoSync本体）をブラウザで開く

   * **HTTPS環境またはlocalhost推奨**
   * 現在地取得にはブラウザの位置情報許可が必要です
2. 位置情報の利用を許可する 📍
3. 上の日付ボタンをタップして、見たい期間のグラフ・表をチェック！

グラフの右上にある「⬇ CSV」「⬇ グラフPNG」ボタンから、表示中データと同じグラフ画像をすぐダウンロードできます。

グラフの下にある「1時間ごとの集計」「ⓘ 用語の説明」ボタンは開閉式なので、必要な時だけパッと開けます。

CSVがほしいときは、粒度に応じて「⬇ CSV（1時間ごと）」「⬇ 日計CSV」を選んでダウンロードしてください。

さらに詳しく気象傾向を見たいときは「📈 過去5年分」、これからの積算値を見たいときは「📊 積算データ」ボタンから、それぞれ専用のグラフ画面に切り替わります（「← 通常表示に戻る」でいつでも元の画面に戻れます）。

## 🇯🇵 時刻はJSTで統一

PhoteoSyncでは、**日本標準時（JST / Asia/Tokyo）を基準として時刻を統一**しています。

```text
現在のブラウザ時刻
        ↓
   JSTの日付を取得
        ↓
 Open-MeteoもJST指定
        ↓
 グラフ・集計・CSV
        ↓
      JSTで表示
```

Open-Meteoから返される時刻も `Asia/Tokyo` を指定して取得し、ブラウザのローカルタイムゾーンに依存しないよう処理しています。

そのため、海外など異なるタイムゾーン設定のブラウザからアクセスした場合でも、PhoteoSync内部では**日本時間を基準にデータを扱います**。

> 📌 緯度・経度そのものはWGS84座標です。
> 「JST化」しているのは座標ではなく、取得・表示・集計する**時刻の基準**です。

## 🌞 昼と夜をグラフで見える化

グラフの背景には、現在地の日の出・日の入りを反映しています。

```text
00:00 ───── 🌙 夜 ───── 🌅 日の出 ───── ☀️ 昼 ───── 🌇 日の入り ───── 🌙 夜 ───── 24:00
              グレー                         白                         グレー
```

### 🌅 通常の日

* 🌙 日の出前 → グレー
* 🌅 日の出 → 昼へ切り替え
* ☀️ 日中 → 白
* 🌇 日の入り → 夜へ切り替え
* 🌙 日の入り後 → グレー

日の出・日の入りの位置は、時間単位のデータ点の間を補間して表示しています。

### 🌌 極夜

太陽が昇らない場合は、その日を**夜間（グレー）**として表示します。

### ☀️ 白夜

太陽が沈まない場合は、その日を**昼間（白）**として表示します。

複数日表示では、それぞれの日付について昼夜を判定するため、日ごとの光環境の変化も直感的に確認できます。

## 📍 現在地・地名取得のしくみ

現在地はブラウザの **Geolocation API** を利用して取得します。

```text
📍 ブラウザの位置情報
        ↓
   緯度・経度（WGS84）
        ↓
🗾 国土地理院 逆ジオコーディング
        ↓
   市区町村・大字など
        ↓
「〇〇市〇〇」として表示
```

緯度・経度は小数点以下6桁で扱い、その地点の気象データをOpen-Meteoから取得します。

国土地理院側で地名情報が取得できない場所では、**緯度・経度のみを表示して動作を継続**します。

## 📊 表示するデータ

| 項目        | 単位         | 内容             |
| --------- | ---------- | -------------- |
| 🌡️ 気温    | °C         | 気温             |
| ☀️ 短波放射   | W/m²       | 全天日射           |
| 🌤️ 直達日射  | W/m²       | 直接届く日射         |
| ☁️ 散乱日射   | W/m²       | 大気などで散乱した日射    |
| 🌤️ 散乱光比率 | %          | 全天日射に占める散乱光の割合 |
| 🌿 PAR    | W/m²       | 光合成有効放射        |
| 💡 PPFD   | μmol/m²/s  | 光合成に利用できる光子量   |
| 🌱 DLI    | mol/m²/day | 1日の積算光量子量      |
| 🌧️ 降雨量   | mm         | 時間ごとの降雨量       |

## 🧪 中の計算、ちょっとだけ覗いてみる？

Open-Meteoから取れる短波放射（全天日射）・直達光・散乱光を使って、以下の近似式で植物向け指標に変換しています。

| 指標                | ざっくり計算式                                            |
| ----------------- | -------------------------------------------------- |
| ☀️ PAR（光合成有効放射）   | 直達光 × 0.43 ＋ 散乱光 × 0.57（散乱光の方がPAR比率高めなので係数を分けています） |
| ☁️ 散乱光比率          | 散乱光 ÷ 短波放射 × 100（%）                                |
| 💡 PPFD（光量子束密度）   | PAR(W/m²) × 4.6（1Wあたり約4.6μmolの光子、というエネルギー→粒数変換）    |
| 🌞 DLI（1日の積算光量子量） | PPFDを1時間ごとに mol/m²/時 に変換して1日分を積算                   |

```text
直達日射 ＋ 散乱日射
          ↓
         PAR
          ↓ × 4.6
        PPFD
          ↓ 積算
         DLI
```

※ あくまで一般的な近似係数を使った目安値です。実測とは多少ズレます。

## 🌿 作物別・目標DLI＆PAR早見表

「用語の説明」の中にひっそりこの表が入っています👇

| 作物      | PAR (MJ/m²/日)         | DLI (mol/m²/日)    | ひとこと                    |
| ------- | --------------------- | ----------------- | ----------------------- |
| 🍅 トマト  | 4.3〜6.5               | 20〜30             | 果菜類は光をよく食べる子            |
| 🥒 キュウリ | 4.3〜6.5               | 20〜30             | トマトと同じくらい光好き            |
| 🍓 いちご  | 4.3〜5.4（最低目安 2.2〜2.6） | 20〜25（最低目安 10〜12） | 光りすぎ（30超）はストレスになるので注意⚠️ |

**参考文献**

* 📄 Virginia Cooperative Extension, *Calculating and Using Daily Light Integral (DLI): An Introductory Guide* (SPES-720)
  https://www.pubs.ext.vt.edu/SPES/spes-720/spes-720.html
* 📄 The Ohio State University, *Photosynthetic Lighting*（Indoor/Controlled Environment Berry Production）
  https://u.osu.edu/indoorberry/photosynthetic-lighting/

品種・作型・CO₂濃度・気温などで最適値は変わるので、あくまで目安として使ってくださいね🙏

> ちなみに目標DLIを大きく超える強い光を浴び続けると、果菜類は多少なら収量増につながりやすい一方、光阻害・葉焼け・高温障害などのストレスが出ることも。特にいちごは30 mol/m²/日超でストレスが出やすいので、真夏は遮光カーテンなどで調整するのがおすすめです☂️

## 📈 グラフ

[Chart.js](https://www.chartjs.org/) を使用しています。

表示する主なデータ：

* 🌡️ 気温
* ☀️ 短波放射
* 🌤️ 直達日射
* ☁️ 散乱日射
* 🌿 PAR
* 💡 PPFD
* 🌧️ 雨量

複数日表示では日付ごとに区切って表示され、**昼夜背景と合わせて光環境の変化を視覚的に確認**できます。

グラフの横幅はデータ量に応じて自動調整され、複数日表示などデータ点が多い場合は横スクロールできます。

## 📅 表示期間

現在を基準に、以下の期間を切り替えられます。

```text
-15日    -7日    -3日

        本日

 +3日    +7日    +15日
```

### 📌 本日

本日の時間別データと、その日のサマリーを表示します。

### 📌 ±3 / ±7 / ±15日

複数日のデータをグラフと日別集計表で比較できます。

### 📌 日付タップ

日別集計表の日付を選択すると、**その日の時間別データへ切り替え**できます。

## 📈 過去5年分の気象比較

「📈 過去5年分」ボタンを押すと、現在地の**過去5年分の気象データ**をOpen-Meteoの過去データAPIから取得し、年ごとに重ねたグラフで比較できます。

```text
📈 過去5年分ボタン
        ↓
 過去5年分のアーカイブデータを取得
        ↓
  年ごとに重ねてグラフ化
        ↓
 7日／14日／30日移動平均で表示
```

* 表示する5つのグラフ：**最低気温・平均気温・最高気温・降水量・短波放射量**
* 今年に近いほど線の色が濃く、過去にさかのぼるほど薄く表示
* 「7日／14日／30日」の移動平均ボタンで、傾向の見え方を切り替え可能
* グラフはドラッグで範囲拡大、ホイール／ピンチで拡大縮小。5つのグラフの表示期間は連動します（「🔍 表示期間をリセット」でいつでも戻せます）
* 各グラフの右上に「⬇ CSV」「⬇ PNG」ボタンを設置。その項目だけを個別にダウンロード可能
* 「⬇ 移動平均CSV」ボタンからは、5項目すべての生値＋移動平均データをまとめて1つのCSVとして出力
* 「← 通常表示に戻る」で、いつでも通常のグラフ表示に戻れます

## 📊 積算データ

「📊 積算データ」ボタンを押すと、カレンダーで**起算日**を指定するだけで、そこから**本日+90日先まで**の気温・短波放射・雨量の積算値をグラフで確認できます。

```text
📊 積算データボタン
        ↓
  カレンダーで起算日を指定
        ↓
 実測・予報データを取得（過去92日〜先16日）
        ↓
足りない期間は過去5年の同日平均で補完
        ↓
  起算日から本日+90日まで積算
        ↓
      グラフ表示
```

* 積算する項目：**積算気温（℃・日）・積算短波放射（MJ/m²）・積算雨量（mm）**
* 実測・予報データでカバーできる範囲（Open-Meteoの過去92日〜先16日予報）はその値をそのまま積算に使用
* それ以外の期間（先16日以降〜本日+90日など）は、**過去5年の同じ月日の平均値**で自動補完しながら積算を継続
* グラフ上部に「⬇ CSV」「⬇ グラフPNG」ボタンを設置。CSVには、各日の積算値に加えて「実測/予報」か「過去5年平均で補完」かを示す備考列も出力
* 「← 通常表示に戻る」で、いつでも通常のグラフ表示に戻れます

> 🌱 起算日を定植日や播種日にすると、その後の積算気温・積算日射量・積算雨量の見通しを立てるのに使えます。

## 📥 CSVダウンロード

PhoteoSyncでは、用途に合わせて4種類のCSVを出力できます。

### ⏱️ CSV（1時間ごと）

グラフ右上の「⬇ CSV」ボタンから、以下の項目を1時間単位で出力します。

```text
日時
気温(°C)
短波放射(W/m²)
短波放射(MJ/m²)
散乱光比率(%)
PAR(W/m²)
PAR(MJ/m²)
PPFD(μmol/m²/s)
降雨量(mm)
```

### 📅 日計CSV

日ごとに集計して出力します。

```text
日付
最高気温(°C)
平均気温(°C)
最低気温(°C)
短波放射(MJ/m²/日)
散乱光比率(%)
PAR(MJ/m²/日)
DLI(mol/m²/日)
雨量(mm/日)
日出
日入
```

### 📈 過去5年分CSV

過去5年分の各グラフ右上「⬇ CSV」から、その項目1つ分の生値＋移動平均データを年ごとに出力します。「⬇ 移動平均CSV」ボタンからは、5項目すべてをまとめて1つのCSVとして出力できます。

```text
月日
（項目）_（年）年_生値
（項目）_（年）年_移動平均
```

### 📊 積算データCSV

積算データグラフの「⬇ CSV」から、起算日〜本日+90日までの積算値を出力します。

```text
日付
積算気温(℃・日)
積算短波放射(MJ/m²)
積算雨量(mm)
備考（実測/予報 または 過去5年平均で補完）
```

CSVはUTF-8のBOM付きで生成するため、Excelなどで日本語を扱う場合にも利用しやすい形式です。

## ⚠️ 注意事項

* 気象データは予報値・推定値を含むため、実測値とは異なる場合があります。
* PAR・PPFD・DLIは日射データからの近似計算です。
* 栽培判断に利用する場合は、実測センサーとの併用を推奨します。
* 積算データの実測・予報でカバーできる期間は概ね「過去92日〜先16日」までで、それ以降の期間（先16日〜本日+90日など）は過去5年の同日平均値による補完値です。実際の気象とは異なる場合があります。
* 過去5年分の気象比較・積算データの平均補完は、Open-Meteoの過去データが取得できる範囲・地点に依存します。
* ブラウザの位置情報取得が許可されていない場合、現在地ベースの表示は利用できません。
* 国土地理院で地名情報を取得できない場所では、緯度・経度のみ表示される場合があります。
* Open-Meteoの利用条件・ライセンスについては、公式ドキュメントを確認してください。
* 日の出・日の入りは天文計算による近似値であり、観測地点の標高や地形、気象条件などによって実際の見え方と差が生じる場合があります。

## 🔤 名前の由来

**PhoteoSync** は、Open‑Meteo の気象データ（GHI・直達光・散乱光・気温など）を用いて、植物の**光合成量・乾物生産・シンク需要**を時系列で可視化する解析ツールという構想から生まれた名前です。

光合成の「光反応（**photo**）」と気象データ（**meteo**）、さらに果実・根・成長点などの**シンク器官（sink）**の需要を**同期（sync）**させることで、植物の生育を「光環境 × 生理 × 収量」の観点から総合的に理解できるように、という思いを込めています。

* **photo**

  * 光合成の光反応を象徴
  * 葉が受け取る光子の量をモデル化

* **meteo**

  * Open‑Meteo の気象データを統合
  * GHI・直達光・散乱光を光合成モデルに投入

* **sync**

  * 光合成産物の流れをシンク（**sink**）と同期
  * 光環境・気象・シンク需要を一体化して解析
  * 「自分の観測・モデル・考察を同期させる」という意味も込めている

> **PhoteoSync** = 光（photo）＋ 気象（meteo）＋ シンク（sink）を同期（sync）するツール
